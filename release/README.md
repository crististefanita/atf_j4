# Catalogul livrărilor

## Pe scurt

Catalogul indică versiunea curentă și păstrează o singură ediție anterioară pentru proveniență.

## Versiunea curentă

[0.19.0 — APK, verificări și proveniență](0.19.0/README.md) este ediția Android curentă. README-ul principal oferă link direct la asset-ul GitHub pentru utilizatorii autentificați cu acces la repository.

## Publicare și verificare

Pregătirea, calificarea și publicarea urmează [procesul de release](../docs/testing/ATF_ReleaseQualification.md) și [ghidul de livrare Android](../docs/platform/ATF_AndroidDelivery.md). Pentru asset-urile cu acces autentificat, verificați descărcarea cu un cont autorizat și confruntați numărul de octeți și hash-ul cu manifestul versiunii. README-ul principal rămâne o pagină de produs și nu afișează hash-uri.

## Citire rapidă

1. Deschideți README-ul versiunii curente pentru scop și pașii de instalare.
2. Urmați raportul Extent canonic; README-ul său explică suitele și proveniența.
3. Consultați manifestul pentru identitatea APK-ului, semnare, calificare și inventarul payload-ului.

Strategia de testare este descrisă generic în [documentația testării](../docs/testing/README.md); rezultatele de mai sus sunt dovezi specifice versiunii.
