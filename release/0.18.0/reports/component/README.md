# Suitele de componente

Fiecare selecție are un raport Extent canonic și un receipt. Raportul și receipt-ul din release sunt copii verificate din aceeași execuție pe sursa fixată; capturile din raport sunt inline, iar XML-ul JUnit și PNG-urile nu sunt duplicate.

Amprenta comună este legată prin source-inputs.json, source-provenance.json și source-component-run.json. Raportul Android E2E este separat în reports/e2e/signed-release-achievements/.
