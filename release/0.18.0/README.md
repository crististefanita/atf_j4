## Descărcare și instalare

APK-ul `WhistLab-0.18.0.apk` este publicat ca asset GitHub pentru conturile autentificate care au acces la repository. Folosiți linkul **Descarcă APK 0.18.0** din README-ul principal sau deschideți [GitHub Release v0.18.0](https://github.com/crististefanita/atf_j4/releases/tag/v0.18.0).
