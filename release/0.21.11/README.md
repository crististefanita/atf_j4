# Whist 0.21.11

## Pe scurt

- Aliniază rangurile cărților din Android cu dimensiunea din Web pentru toate cărțile de la 2 la A, inclusiv 10 și J/Q/K.
- Îmbunătățește lizibilitatea rangurilor, păstrând proporțiile cărților, dimensiunile simbolurilor și tipografia chenarului de atu.
