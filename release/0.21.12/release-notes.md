# Whist 0.21.12

Rolurile comune ale textului păstrează scorul consecvent între Android și Web și respectă mărirea accesibilă. Calificarea livrării verifică mai strict publicarea și recuperarea.

## Îmbunătățiri față de 0.21.11

- Aliniază tipografia scorului între Android și Web prin roluri comune ale textului, compatibile cu accesibilitatea.
- Întărește validarea notelor de release, identificarea utilizatorilor Android și reutilizarea dovezilor de componentă legate de surse.
