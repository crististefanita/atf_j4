## Stare și scop

- Calificarea derivată din surse a trecut.
- A rulat suita de guvernanță/componentă afectată; nouă grupuri neschimbate au reutilizat dovezi legate de hash-urile sursă originale.
- Diferența de surse nu a schimbat comportamentul jocului sau al interfeței, deci RAG nu a selectat fluxuri E2E.
- API-ul GitHub autentificat a returnat APK-ul și checksum-ul cu hash-uri identice.
