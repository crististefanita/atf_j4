# Whist 0.22.1

Actualizările RAG de mentenanță aleg componentele în funcție de proprietatea sursei și reutilizează dovezile validate pentru modulele neschimbate.

## Schimbări

- Reutilizează dovezile componentelor numai când hash-urile sursei deținute și proveniența coincid.
- Rulează suita afectată de guvernanță/componentă; diferența surselor nu a selectat fluxuri E2E de joc sau interfață.
- Construiește și semnează APK-ul Android 0.22.1 cu certificatul existent pentru canalul de test autentificat.
