# Whist Lab 0.20.0 — aplicație Android

## Pe scurt

Ediția actualizează antetul mesei și catalogul realizărilor, folosind biblioteca UI comună.

## Descărcare și instalare

- [Descarcă APK-ul 0.20.0](https://github.com/crististefanita/atf_j4/releases/download/v0.20.0/WhistLab-0.20.0.apk)
- [Pagina release-ului v0.20.0](https://github.com/crististefanita/atf_j4/releases/tag/v0.20.0)

Instalarea folosește pachetul Android al ediției Whist Lab.

## Schimbări

- Bifa Automat este lângă titlu sau pe propriul rând la text mărit. Atuul și informațiile mâinii sunt dedesubt.
- Catalogul Realizări păstrează ordinea de învățare și afișează progresul și condiția fiecărui obiectiv.
- Componentele vizuale sunt organizate în modulul reutilizabil atf-card-table-ui.
