# Whist Lab 0.21.0

## Pe scurt

Ediția extinde catalogul de realizări și păstrează progresul existent.

## Descărcare și instalare

- [Descarcă APK-ul 0.21.0](https://github.com/crististefanita/atf_j4/releases/download/v0.21.0/WhistLab-0.21.0.apk)
- [Pagina release-ului v0.21.0](https://github.com/crististefanita/atf_j4/releases/tag/v0.21.0)

Instalarea folosește pachetul Android al ediției Whist Lab.

## Schimbări

- Adaugă 15 realizări pentru contracte de zero, licitații pozitive și reveniri după ratări.
- Păstrează ID-urile, pragurile și progresul celor 40 de realizări existente.
- Clarifică ordinea mâinilor pentru 8–1–8 în ajutorul român și englez.

## Calificare

- Componentele au 1207 invocări trecute.
- Catalogul a fost verificat pe APK-ul semnat, în Android API 28 headless.
